# сервисы

## 1. Bid
Обиен Request/Response
### rate limit 
- по кличенту 18000 rps 
- по сервису 50000 rps
### retry
- 2 раза сервис кретичин по latency увеличение retry бессмысленно Фиксированная задержка
### fallback
В случае ошибки возвращать статус аукциона не состоялся

## 2. Banner
Показ рекламы
rate limit 
- по сервису 50000 rps
### retry
- 3 раза Экспоненциальный backoff с джиттером
### fallback
В случае ошибки возвращать 500
