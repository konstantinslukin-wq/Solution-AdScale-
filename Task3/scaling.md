# Репликаци 
## Сервис компаний 
PostgreSQL Master-Slave с несколькими read-replica с балансировкой по нагрузке если возрастает нагрузка по текущим репликам до добавить новых
обусловленно относительно малым количеством операций записи и большим чтения + необходимость в получение данных по всем компаниям для поиска кандидатов
#  Шардирование
## Сервис финансов
PostgreSQL с динамическим хеширование по ключу компании.
Обусловленно с большим количеством операций записи(списание средств при показе)
## Сервис ставок
PostgreSQL сохраняем результаты аукциона динамическое шардирование по хешу ID аукциона
